Au futur, les terminaisons sont toujours les mêmes :
je → -ai   tu → -as   il / elle / on → -a
nous → -ons   vous → -ez   ils / elles → -ont
Mais avec les verbes du 3e groupe, le radical change souvent !
Exemple : aller → j'irai. Utilise le « coup de pouce » pour connaître le radical.
